# Generador de contraseñas / Password generator

Programa en Python que genera contraseñas seguras al azar.
Python program that generates secure random passwords.

## Características / Features
- Funciona en español e inglés / Works in Spanish and English
- Acepta el largo con números o en letras (por ejemplo: 25, veinticinco, twenty-five)
- Opción de incluir símbolos (s/n, sí/no, y/n, yes/no)
- Usa la librería `secrets`, pensada para seguridad

## Cómo usarlo / How to use
1. Instala Python 3
2. Ejecuta / Run: python generador.py
3. Elige el idioma y responde las preguntas
